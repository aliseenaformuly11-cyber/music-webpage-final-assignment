# Ali Seena Music Website

This repository contains the complete Visual Studio ASP.NET Core project for the
Visual Studio final assignment.

## Assignment requirements completed

- HTML webpage with an embedded YouTube music video
- Custom CSS styling, fonts, colours, and responsive layout
- JavaScript-powered moving, spinning, and bouncing record animation
- Complete Visual Studio solution and ASP.NET project files

## Project structure

- `AliSeenaMusicWebsite.sln` — Visual Studio solution
- `AliSeenaMusicWebsite.csproj` — ASP.NET Core project configuration
- `Program.cs` — application startup and static-file configuration
- `Properties/launchSettings.json` — Visual Studio launch profiles
- `wwwroot/index.html` — main webpage
- `wwwroot/styles.css` — custom styling
- `wwwroot/script.js` — JavaScript animation and controls

## Open and run in Visual Studio

1. Open Visual Studio 2022.
2. Select **Open a project or solution**.
3. Choose `AliSeenaMusicWebsite.sln`.
4. If prompted, allow Visual Studio to restore the project.
5. Press **Ctrl+F5** to run the website without debugging.

The project targets .NET 8. Install the **ASP.NET and web development** workload
through the Visual Studio Installer if Visual Studio says the required components
are missing.
